Airfare Price Prediction using Python | End-to-End Predictive Analytics

This project analyzes historical airline fare data to identify key factors associated with airfare levels and build a predictive model for route-level pricing analysis. The analysis combines Exploratory Data Analysis, regression modeling, model selection, validation, lift analysis, and scenario modeling to translate statistical results into practical business insights. Key outputs include a BIC-selected regression model, validation performance assessment, prospective fare estimation, competitive benchmarking, and a pre-operation pricing model using information available before a route begins. The project demonstrates how data analysis and predictive modeling can be applied to support pricing decisions and business planning.

Bike Sales Data Cleaning & Excel Dashboard

This project demonstrates an end-to-end data preparation and business reporting workflow using a bike sales dataset in Microsoft Excel. The analysis begins with data cleaning and preparation to improve data quality and consistency, followed by the creation of PivotTables to summarise sales performance across key business dimensions. An interactive Excel dashboard was then developed to present the results through KPIs, charts, and visual summaries. The project demonstrates practical Business Analyst skills in data cleaning, exploratory analysis, data summarisation, dashboard development, and business-focused reporting.
